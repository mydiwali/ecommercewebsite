TROUBLESHOOTING QUICK REFERENCE
================================================================================

Problem: "Page Not Found" (404)
→ Solution: Check .htaccess files, AllowOverride=All in Hostinger

Problem: "Can't Connect to Database"
→ Solution: Verify api/config.php credentials match Hostinger

Problem: "Coupon Box Not Showing"
→ Solution: Check browser console (F12) for JS errors

Problem: "API Returns Error"
→ Solution: Check Network tab (F12) for HTTP status

Problem: "SSL Certificate Error"
→ Solution: Wait 24-48h for Let's Encrypt, clear cache

→ More help: See HOSTINGER_QUICK_SETUP.md "Common Issues & Fixes"

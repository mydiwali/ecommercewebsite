## 🆘 Troubleshooting

### "404 Not Found"
- Check all `.htaccess` files are uploaded
- Enable `AllowOverride All` in Hostinger

### "Can't Connect to Database"
- Verify `api/config.php` credentials
- Test in phpMyAdmin

### "Coupon Box Not Showing"
- Open browser console (F12)
- Check for JavaScript errors

### "API Returns Error"
- Check Network tab (F12)
- Verify database credentials
